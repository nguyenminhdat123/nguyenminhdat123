### Projects

**6-DOF Spray Painting Robotic Arm** — Research project

Robotic arm with automatic (vision) and manual (teach pendant) modes.
- D–H model, forward and inverse kinematics and trajectory simulation in MATLAB
- Mechanical design in SolidWorks (3D printed); 2-layer control PCB in Altium
- Raspberry Pi as main processor, STM32 firmware in C driving six stepper motors
- Object detection with OpenCV and YOLO to give the arm its painting positions
- Web dashboard for remote monitoring, live camera, sensors and emergency stop

*Stack: STM32 (C), Raspberry Pi, Python, OpenCV, YOLO, JavaScript, MATLAB, SolidWorks, Altium*

**Smart Parcel Receiving Locker – IoT System** — Course project

Unstaffed parcel locker with a three-layer node – gateway – server architecture.
- ESP32 locker node with custom PCB (sensors, electronic locks, LoRa module)
- ESP32 gateway forwarding data from LoRa to the server over MQTT
- Node.js backend with REST APIs and MySQL; web app for users and admins
- Secured with HTTPS and MQTTS (TLS); tested end to end

*Stack: ESP32 (C/C++), LoRa, MQTT/MQTTS, Node.js, JavaScript, MySQL*
